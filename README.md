# perlwasm2go

wasm2go sources for `perl.wasm` — a pure-Go translation (no cgo, no wasm
runtime) of the Perl 5 interpreter, generated by
[wasmify](https://github.com/goccy/wasmify) /
[wasm2go](https://github.com/goccy/wasm2go) from the `perl.wasm` that
[perl-wasm](https://github.com/goccy/perl-wasm) builds out of Perl 5.42.2.
[go-perl](https://github.com/goccy/go-perl) consumes this module.

Everything in this repository except the scaffolding (`Makefile`, CI, license
files) is generated code vendored from a perl-wasm release — nothing is edited
by hand.

## Updating to a new perl-wasm release

```sh
make bundle PERL_WASM_VERSION=v0.1.1
```

`bundle` downloads `perl_wasm2go.tar.gz` + `perl_wasm2go.sha256` from the
release, extracts them over the repo, and then verifies:

- `verify-release` — every in-tree file byte-matches the sha256 manifest.
- `verify-attestation` — every in-tree file is a signed subject of the
  release's SLSA build-provenance attestation, checked offline with
  `gh attestation verify --bundle` against perl-wasm's `release.yml` as the
  signer workflow.

CI runs the same `make verify` on every push and pull request, so the tree can
only ever contain bytes that provably came out of a perl-wasm release build.
